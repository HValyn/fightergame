# Google Flow prompt checklist

Generated by `tools/sprite_pipeline/pipeline.py prompts`. Do not edit; edit `art_spec.toml`.

## How to use

1. Open Google Flow (labs.google/flow), create an image project, pick the best image model on offer.
2. **Make the character reference first** (prompt below each character). Pick the best one, save it as `flow_raw/<char>/reference.png`, and attach it as an *ingredient* / reference image for every other prompt of that character so the design stays consistent.
3. Generate each pose. Choose the variant whose proportions best match the reference, download it, and save it under `tools/sprite_pipeline/flow_raw/` with the exact file name shown.
4. Do tier 1 first. The game falls back gracefully: missing attacks use the generic `punch`/`kick` art, missing poses use `idle`, and a character with no art uses the procedural placeholder.
5. Run `pipeline.py process`, then run the game.

Tips: keep the green background flat (re-roll if the model adds a floor or shadow). Loops (idle, walk) can also be one image with all frames side by side, saved as `<anim>_strip.png`.
