# Rig art prompts (Skeleton2D route)

Generated by `tools/rig_art/rig_prompts.py prompts`. Do not edit; edit `roster.toml`.

## How to use

1. Open Google Flow (or Gemini) with the best image model on offer.
2. Generate the **reference** first. It defines the fighter. Re-roll until it is a clean side view facing right, arms slightly away from the body, nothing cut off. Save it as `rig_raw/<id>/reference.png`.
3. Attach `reference.png` as an ingredient/reference image for the other three prompts.
4. Parts sheets: re-roll if parts touch or overlap, or if a joint has no rounded overlap. Missing pieces can be generated on their own afterwards (same prompt, ask for one part).
5. Real photos help most: attach a photo of the actual garment or pattern (pakol, ajrak, phulkari, Swati embroidery, Baloch pudo pocket) next to the reference when the model gets it wrong.

Rig the `easy` fighters first. `hard` ones have a lot of loose cloth that needs mesh deformation.
